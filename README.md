# BusVisa — Global Visa Map

**v0.3.2 · 邀请制内测**

BusVisa 是面向移动浏览器的全球签证地图。根据所选护照和已登记的签证类型，展示目的地入境方式、条件性便利和参考费用，帮助你整理旅行证件并了解出行要求。

[访问网站](https://busvisa.netlify.app/) · [GitHub 仓库](https://github.com/zaneku/BusVisa) · [版本历史](CHANGELOG.md)

## 主要功能 / Features

- **世界通行地图**。根据护照和已登记签证，以不同颜色展示目的地入境方式，点击国家或地区查看详细条件与参考来源。
- **护照与签证记录**。选择护照签发国家或地区，按签发地添加签证类型，也支持手动填写签证类别。
- **多语言搜索**。护照、签证签发地和目的地支持中英文搜索。
- **政策同步**。在线更新护照入境政策，查看来源及政策变化记录。
- **费用与汇率参考**。查看落地签参考费用，以及当地币种与人民币的参考换算。
- **四种界面语言**。支持简体中文、繁體中文（香港）、繁體中文（台灣）及 English。
- **外观设置**。支持浅色、深色及跟随系统模式。
- **移动端体验**。适配手机浏览器，并提供添加到主屏幕的应用图标。

## 开始使用 / Getting started

1. 打开网站，使用获得的邀请码进入内测。
2. 选择自己的护照签发国家或地区。
3. 根据需要添加已持有的签证及其类别。
4. 在地图中查看目的地，阅读入境条件、费用及参考来源。

语言、外观、关于和使用说明位于签证页底部的设置中。应用页面需联网加载，出行前请重新核对政策来源。

## 隐私与本地存储 / Privacy

护照选择、个人签证记录、语言和外观偏好保存在当前浏览器本地。清理网站数据或更换浏览器、设备后，需要重新录入相关记录。

应用不记录或验证签证有效期及入境次数。添加签证后展示的通行便利仍需结合实际证件和目的地规定核实。

## 使用说明与免责声明 / Usage notes

- BusVisa 提供第三方入境政策参考。出发、购票和办理登机手续前，请核对目的地政府与承运航司的最新要求。
- 护照和已登记签证用于生成条件性提示。实际入境资格还涉及有效期、入境次数、签证签发地、首次使用及其他附加条件。
- 参考费用与汇率存在更新周期，实际办理或结算金额以服务提供方为准。
- 地图仅作为签证与入境政策的示意展示。地图中的国界、地区边界及地理标注不代表真实或法定边界，也不构成对任何领土归属或边界划分的认定。
- 签证页的设置与关于中提供完整的四语言使用说明，以及未成年人和监护人提示。
